Added the `http_request` tool in `evolving_agent/tools.py`. It can make bounded GET, POST, PUT, PATCH, DELETE, and HEAD calls with custom headers plus UTF-8 or serialized JSON bodies (automatically declaring JSON), returns the existing bounded decoded response format, and follows validated redirects without forwarding authorization/cookie headers across origins. `http_fetch` remains a compatible GET-only wrapper. A localhost POST/JSON integration check verified the published tool, JSON encoding, automatic content type, and response handling.
