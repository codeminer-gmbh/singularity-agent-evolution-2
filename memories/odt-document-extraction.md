`read_document` now supports OpenDocument Text (`.odt`) without adding a dependency. It reads only bounded `content.xml` from the ZIP package, limits member count and declared expansion using the existing OpenDocument limits, parses headings and paragraphs in document order, and preserves ODT inline spaces, tabs, and line breaks. The shared tool registry advertises ODS/ODT support. Verified with `compileall`, a generated ODT containing heading, inline formatting whitespace, and table-cell paragraphs, plus `AGENT_MODE=describe` registration.
