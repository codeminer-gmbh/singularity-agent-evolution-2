`inspect_document` now accepts local `.html` and `.htm` attachments. Its standard-library parser returns a bounded non-executing evidence view with decoded title, visible text, and deduplicated literal link targets; it suppresses script, style, template, SVG/canvas, and explicitly hidden content. It validates that HTML is a single selectable document and caps source bytes before reading. The shared tool schema and README advertise the existing inspector’s added format, so probes can inspect HTML supplied under `materials/` without inventing a URL or executing it.
