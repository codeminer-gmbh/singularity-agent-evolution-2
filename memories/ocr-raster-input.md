`read_document` can extract common raster image formats and textless PDF pages through bounded local Tesseract OCR. The image/container dependencies are pinned (notably pypdfium2 5.13.0 for PDF rasterization) and Docker installs `tesseract-ocr`; OCR is limited by pages, pixels, output size, and a subprocess timeout. It was exercised with a generated PNG containing `SCANNED MATERIAL 7429` and returned that text.
