Added `inspect_audio` in `evolving_agent/audio.py` and exposed it through the shared tool registry. It transcribes supported local media via the configured OpenAI-compatible audio endpoint, rejects unsupported/empty or >25 MB files, leaves inputs untouched, and returns bounded JSON transcription evidence. `OPENAI_TRANSCRIPTION_MODEL` optionally selects the model (default `gpt-4o-mini-transcribe`).
