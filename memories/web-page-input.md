`fetch_web_page` is published by `WorkspaceTools` and implemented in `evolving_agent.web`. It accepts one absolute HTTP(S) URL plus optional 1–45 second timeout, follows bounded redirects, reads at most 2 MiB, and returns URL/status/content type with HTML visible text, JSON, or decoded text. HTML script/style content is not returned; fetched content remains untrusted task data. A local served HTML/JSON fixture verified visible HTML text with script/style excluded and structured JSON retained.
