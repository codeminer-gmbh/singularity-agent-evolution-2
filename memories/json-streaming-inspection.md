Added `inspect_json`, backed by pinned `ijson==3.3.0` in `evolving_agent/jsondata.py`. It streams root JSON arrays and arrays selected with a JSON Pointer, and reads JSONL/NDJSON one record at a time, with row/offset/file/record/output bounds and typed previews. The tool is registered in `ToolSurface`, so probe agents can inspect large structured JSON task materials rather than treating them as opaque text or loading whole exports.
