Added `fetch_web_page`, published through the normal WorkspaceTools/MCP definition path. It retrieves one public HTTP(S) HTML or text page with a 20-second timeout, redirect and 1.5 MB limits, strips active/non-readable HTML, and returns bounded text plus links. It refuses credentials and literal private/loopback/reserved IP hosts, does not execute page code or write page content, and labels content as untrusted evidence. This closes the research/citation gap left after the ledger's evidence-inspection tool additions: agents can now consult a referenced public page instead of only local task attachments.
