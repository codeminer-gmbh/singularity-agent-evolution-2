Added `evolving_agent/raster.py` and the published `inspect_raster` tool. It uses pinned Rasterio 1.4.3 to report GDAL raster metadata (dimensions, bands, CRS, bounds, transform, nodata, color interpretation, descriptions, and overviews) and a JSON-safe masked pixel preview from one band. Reads are bounded to at most 10,000 pixels; callers may select a clipped `[column_offset, row_offset, width, height]` window. The tool is wired through the existing workspace path resolver, so it supports workspace, `materials/`, and `output/` paths without bypassing containment. Verified against a generated two-band georeferenced GeoTIFF, including nodata conversion and rejection of an oversized requested window.
