Added `inspect_raster`, backed by pinned rasterio, for GeoTIFF and other GDAL-readable local rasters. It returns JSON metadata (driver, dimensions, bounds, CRS, affine transform, nodata, data types, and color interpretations) plus a single-band pixel window; nodata and non-finite values are JSON null. Explicit windows and default previews are bounded to 10,000 cells, and paths still flow through the normal workspace resolver. Verified with a two-band EPSG:4326 GeoTIFF, including nodata masking and cap rejection.
