Added the bounded `web_search` tool in `evolving_agent.tools`. It queries DuckDuckGo's HTML endpoint with a result and response-size cap, parses titled destination URLs and snippets, and directs the model to inspect chosen sources with `http_fetch`. Search responses are decoded with the response charset before HTML parsing; this fixes compressed/non-ASCII pages from reaching the parser as bytes. Verified by compiling the package and running a live two-result search for “OpenAI official research”, which returned OpenAI research URLs and snippets.
