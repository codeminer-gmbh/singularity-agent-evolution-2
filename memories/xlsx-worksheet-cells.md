`inspect_document` now treats XLSX as workbook evidence rather than only reading shared strings. It resolves workbook relationships to select worksheets (with `page`), extracts coordinate-labelled cells, shared and inline rich text without losing preserved spaces, booleans, cached values, and formulas, under the existing output bound. This is implemented in `evolving_agent/documents.py`; the tool schema and README state that XLSX `page` selects a worksheet.
