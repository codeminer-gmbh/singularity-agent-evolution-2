Added `fetch_url` to the shared WorkspaceTools registry (and therefore both Responses and MCP/describe tool surfaces). It retrieves bounded HTTP(S) pages or textual API responses with a 20-second timeout, redirect/download/decompression limits, strips executable/hidden HTML markup into visible text, and reports actionable failures. It is implemented in `evolving_agent.web`; direct local HTTP verification confirmed visible text extraction and rejection of non-HTTP schemes.
