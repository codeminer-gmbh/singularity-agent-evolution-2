Added `inspect_office_document` to the shared MCP/OpenAI tool registry. It safely treats DOCX, PPTX, and ODT as bounded local ZIP/XML evidence: it rejects symlinks, suspicious archives, malformed XML, unsupported formats, and uses only selected XML text/metadata parts without following relationships, external links, macros, embedded files, or active content. The model can now inspect paragraph/slide/section text and basic metadata from common office documents under `materials/`.
