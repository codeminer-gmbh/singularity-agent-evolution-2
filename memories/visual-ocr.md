Added the `ocr_visual` tool for evidence that has no embedded text: it OCRs common raster formats and scanned PDFs (including page/frame limits) with Pillow, PyMuPDF, pytesseract, and the image-provided Tesseract binary. Output preserves page/frame labels and dimensions and is bounded by tool result limits. Verified against generated PNG and image-only PDF containing `SCAN 48291`.
