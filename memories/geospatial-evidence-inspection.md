Added `inspect_geospatial`, a bounded read-only vector-evidence tool for GeoJSON, KML, GPX, standalone ESRI Shapefiles, and ZIP archives containing one Shapefile. It normalizes features into a typed DuckDB `data` view with feature id, geometry type/JSON, properties, and geographic bounds; schema inspection and single read-only SQL queries mirror existing tabular inspectors. PyShp is pinned for Shapefile parsing without GDAL.
