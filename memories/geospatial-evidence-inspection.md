Added `inspect_geospatial` for bounded, read-only inspection of GeoJSON/JSON, KML, KMZ, GPX, and `.shp` map evidence. It reports feature/geometry counts, property fields, finite geographic bounds, compact feature previews, and supports one-based `feature_index`; it is registered in the shared tool registry. `pyshp==2.3.1` supplies Shapefile reading. Verification created temporary GeoJSON, GPX, KML, KMZ, and Shapefile fixtures, checked summaries/bounds and registry exposure, and compiled all Python modules.
