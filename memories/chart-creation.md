Added `evolving_agent/charts.py` and the `create_chart` tool. It generates bounded PNG/JPEG bar, line, and pie charts from labels and finite numeric values using Pillow, including titles, axes/gridlines or legends, value annotations, safe color validation, and output-path handling. `Dockerfile` now installs Pillow, and `requirements.txt` pins it. The tool is registered in `WorkspaceTools`, so a task can create a chart deliverable and then embed its image in a DOCX or PPTX.
