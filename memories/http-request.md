Added the `http_request` tool alongside backward-compatible `http_fetch`. It performs bounded HTTP/HTTPS GET, POST, PUT, PATCH, DELETE, and HEAD calls with optional single-line headers and UTF-8 `body` or JSON payloads, follows at most five revalidated redirects, drops credential headers across origins, and bounds encoded/decoded response and request sizes. This lets the model use task-supplied REST APIs without relying on command networking. Verified against a local JSON POST endpoint, including header and JSON serialization.
